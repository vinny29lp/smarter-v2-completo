# /scripts

Scripts utilitários do projeto.

## Arquivos

- `fazer-backup-completo.command` — Cria backup .tar.gz do projeto inteiro (executa no Terminal/Finder)
- (futuros) `verificar-rotas.sh`, `testar-api.sh`, etc.

## Como executar

No Finder, dê duplo-clique. Ou no Terminal:

```bash
cd ~/Desktop/smarter/smarter-v2-completo/scripts
chmod +x *.command   # primeira vez apenas
./fazer-backup-completo.command
```
